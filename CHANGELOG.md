# Changelog

All notable user-visible changes to the Homebox TOS application package.

## 0.27.1-1 — 2026-11-14

### Added
- First release. Homebox (`sysadminsmedia/homebox:0.27.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8144 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/homeboxdocker/`.
